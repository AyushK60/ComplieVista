   nondeterministic output violates the demo policy; replaced with an honest
   suspended-frame check, and the expected output now demonstrates the iterator
   protocol (manual `next()` consumes a value).

   `demos/C-05/`.
3. The standard C build-failure path swallowed real linker diagnostics
   ("build produced no executable") — now surfaces the compiler/ld stderr tail,
   which the Error Microscope link fixture relies on.
