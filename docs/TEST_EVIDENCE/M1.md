## Known issues / limitations

1. Vite on /mnt/e requires `usePolling` (measured in M0); applied.
2. GitHub unauthenticated rate limit (60/h) — typed `RATE_LIMITED`, no silent retries.
3. Classification is deliberately lexical/AST-level; `main(` inside a comment is a
   recorded false-positive risk labeled `detected`/unverified (test-pinned).
4. Binary assets in imported repos are rejected entries, not browsable (ADR-0004).
5. Frontend "Analyze" is disabled with an explanation: arbitrary-source analysis arrives
   in M2, execution in M4. No stage is faked.
6. The live dev servers used for E2E run from the working tree; DB (`data/`) is gitignored.
