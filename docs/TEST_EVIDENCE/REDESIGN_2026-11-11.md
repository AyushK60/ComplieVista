## What the run found and fixed

- **C tokens were dropped for header-heavy programs.** `parse_dump_tokens_full` stopped at 8000 tokens; clang
  lists included headers first, so C-04 (stdio.h and stdlib.h) lost every token of its own file. The parser
  now reads the whole dump (own-file tokens served first, `tokens_primary_file` counted). Regression test:
  `test_c_tokens_survive_a_header_heavy_dump`. `ANALYSIS_POLICY_VERSION` is now `m2.analyzer.v2`, so earlier
  cached C analyses re-run on demand.
- **Compare could pile work onto the single experiment worker.** Cards re-enabled when polling changed the
  status from the client's "running" to the server's QUEUED/RUNNING. They now stay locked until a final state.
  The experiment detail also reports `queue_ahead`.
- **Contrast failures** introduced by the new palette (signal colour, coral text on paper, an opacity rule)
  were caught by the axe suite and fixed.
- **Tests that read rendered text** now compare case-insensitively, because headings are set in capitals by CSS
  and `inner_text` follows `text-transform`.
- **Launcher:** the port-in-use error now names the real owner (name, pid, command line). Installing frontend
  dependencies with Windows npm replaces WSL's Linux native build binaries; install from WSL (`Setup.cmd`).
