## Known issues / limitations

1. GitHub unauthenticated rate limit (60/h) — typed RATE_LIMITED; cached pinned snapshots
   are reused where possible; skipped tests are never counted as passes.
2. Clang `range.end`/offset-derived lines for brace-delimited statements are labeled
   DERIVED (documented in ADR-0005); token/AST/bytecode positions from CPython and clang
   loc lines remain EXACT.
3. Whole-TU AST includes headers; the tree roots are filtered to the user's file while
   `ast_nodes` keeps the full honest count (both surfaced).
4. Multi-file linked builds and runtime execution remain out of M2 scope (M4 gate).
