## Known limitations

1. **GDB/ptrace: UNSUPPORTED by policy** — C call/return via `-finstrument-functions`
   (compiler instrumentation, not ptrace); no frame-step, no breakpoints, no registers,
   no memory contents. Documented in ADR-0007.
2. **Trace caps**: 5000 events, 64 frames, 200 locals/frame, 120 bytes/value;
   `events_truncated` flag set honestly when the cap fires.
3. **GitHub imports NEVER execute** — `EXECUTION_ORIGIN_BLOCKED` fail-closed.
4. **Arbitrary pasted execution**: local restricted containers only; public/semi-public
   deployment still requires the M9 deployment threat review (README §10, §21).
5. Trace overhead measured separately: ~trace events vs wall clock; visible in output.
6. Single worker thread per runner (analysis + execution each); local-only concurrency.
