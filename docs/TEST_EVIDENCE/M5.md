### G1 — C memory evidence (real, labeled)
- **Allocator interposition** (`sandbox/*/c_trace_shim.c`): real addresses, sizes,
  lifetime order for libc-malloc allocations; capped 5000 events + truncated
  marker. Verified live: `malloc(16)` in the curated fixture is observed; the
  **double-free fixture reproduces the REAL glibc `double free` abort** in
  stderr inside the restricted container with both frees logged
  (`test_c_double_free_reproduces_real_memory_safety_warning`).
- **Frame locals/pointers for pasted C: explicit `unavailable`** (first record
  in the stream, ADR-0008) — no fabrication.
- **Curated gdb debug profile** (`compilevista/debug:m5` + `c_debug_worker.py`):
  real args/locals/addresses via gdb under cap-drop ALL / no-new-privileges /
  uid 1000 — **no SYS_PTRACE, no privilege expansion** (feasibility proven
  live). Curated-only admission by content hash; `values[2] = 30` observed via
  gdb in E2E; every stop carries tool=gdb + ASLR caveat. Non-curated snapshots
  and Python are refused with 403 `DEBUG_PROFILE_BLOCKED`.
- Debug build omits `-finstrument-functions`: the entry hook shifted gdb's
  breakpoint ahead of argument setup — garbage args observed, root-caused, fixed.

## Known limitations

1. gdb parsing untrusted DWARF/ELF remains out of scope — curated content only.
2. RSS sampling at 50 ms misses sub-interval spikes; samples are labeled as such.
3. The object graph is a bounded reachable subgraph from module globals, not
   full-heap coverage; caps are recorded in every payload.
4. ASLR makes C addresses unstable across runs (caveat attached to every stop).
5. Ephemeral debug/dev scripts were removed; evidence lives here and in
   `docs/TEST_EVIDENCE/m5/`.
